How to write helpful SEO title tags and meta descriptions

A search result should help someone understand what a page offers before they click. A clear title and an accurate description make that choice easier.

What is a title tag?

The title tag is the page title provided in the HTML document. Search engines may use it as the clickable headline in search results, though they can generate a different title when another page element better describes the result. Write a distinct title for each important page.

How to write a useful title

  • Describe the page's actual subject or function.
  • Put the most distinguishing words near the beginning when that reads naturally.
  • Make each page title meaningfully different from the others on your site.
  • Avoid repeating keywords, vague claims and unnecessary branding.
  • Make sure the visible page heading agrees with the title's promise.

Example: “Free Online Word Counter — Words & Characters” is more informative for a counting tool than “Best Amazing Tool”. It names the task and clarifies what the visitor can measure.

What is a meta description?

A meta description is a short summary in the page's HTML head. Search engines may use it to create the search-result snippet, but they can also select text from the page that better matches a query. Treat it as a helpful summary, not a guaranteed snippet or a direct ranking shortcut.

How to write a useful description

  1. Summarise the page accurately in plain language.
  2. Explain the practical benefit or information the visitor will find.
  3. Use the main topic naturally, without stuffing keywords.
  4. Keep the description specific to that page.
  5. Do not promise features the page does not provide.

Example: “Count words, characters, sentences and paragraphs as you write. Use this free browser-based counter for essays, articles and social posts.” This explains the function and likely use cases without claiming guaranteed results.

Are there ideal character limits?

Search-result display is not governed by one fixed character limit. Titles and snippets can be shortened or rewritten depending on device width and the search. Character counters are useful editing guides, but prioritise clarity and accuracy over hitting an exact number.

Frequently asked questions

Do meta descriptions improve rankings?

A description can help a searcher understand a result and decide whether it is relevant. It is not a guaranteed ranking boost, and Google may choose a different snippet.

Should every page have the same title?

No. Give each important page a distinct title that accurately describes its own content.

PRIVACY

Your text stays in your browser.

This page explains the current data practices for HAQS.

Text entered into tools

Current HAQS tools process text in your browser using JavaScript. The project does not currently send text entered into tools to a HAQS server or store it in a HAQS account.

Cookies, analytics and advertising

The current version does not intentionally set analytics or advertising cookies. If such services are added later, this page must be updated to explain those services and visitor choices.

External links

HAQS may link to third-party websites. Their privacy practices are controlled by those providers.
